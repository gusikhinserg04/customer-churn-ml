# Прогнозирование оттока клиентов (Customer Churn Prediction)

Проект машинного обучения для прогнозирования оттока клиентов телекоммуникационной компании на основе датасета Telco Customer Churn.

## О проекте

Отток клиентов — одна из ключевых проблем компаний, работающих по подписочной модели. Своевременное выявление клиентов, которые могут отказаться от услуг, помогает лучше понимать поведение пользователей и разрабатывать стратегии удержания.

Цель проекта — построить модель бинарной классификации, которая прогнозирует, уйдёт ли клиент из телекоммуникационной компании.

## Задачи проекта

* Загрузка и первичный анализ данных.
* Очистка данных и обработка пропущенных значений.
* Подготовка числовых и категориальных признаков.
* Обучение модели машинного обучения.
* Оценка качества предсказаний на тестовой выборке.
* Сохранение обученной модели для дальнейшего использования.

## Используемые технологии

* **Python** — основной язык программирования.
* **Pandas** — обработка и анализ данных.
* **NumPy** — математические вычисления.
* **Scikit-learn** — подготовка данных, обучение и оценка модели.
* **Joblib** — сохранение обученной модели.

## Этапы работы

1. **Загрузка данных.** Чтение исходного CSV-файла.
2. **Предобработка.** Проверка данных, удаление дубликатов и обработка пропусков.
3. **Подготовка признаков.** Преобразование `TotalCharges` в числовой формат и исключение идентификатора клиента из признаков.
4. **Разделение выборки.** Разделение данных на обучающую и тестовую части в соотношении 80/20.
5. **Преобразование признаков.**

   * Числовые признаки: заполнение пропусков медианой и стандартизация.
   * Категориальные признаки: заполнение пропусков наиболее частым значением и One-Hot Encoding.
6. **Обучение модели.** Использование Logistic Regression с балансировкой весов классов.
7. **Оценка качества.** Расчёт метрик классификации на тестовой выборке.
8. **Сохранение модели.** Сериализация обученного конвейера с помощью Joblib.

Предобработка данных и классификатор объединены в единый конвейер Scikit-learn.

## Оценка качества модели

Для оценки используются следующие метрики:

* **Accuracy** — доля правильных предсказаний.
* **ROC-AUC** — способность модели различать клиентов, которые уходят, и клиентов, которые остаются.
* **Precision** — точность положительных предсказаний.
* **Recall** — доля выявленных клиентов, склонных к оттоку.
* **F1-score** — гармоническое среднее Precision и Recall.
* **Confusion Matrix** — матрица ошибок классификации.

Фактические значения метрик выводятся при запуске скрипта. Они не указаны в описании, поскольку должны быть подтверждены результатами выполнения модели.

## Установка и запуск

### Требования

* Python 3.10 или новее.
* Git.

### 1. Клонирование репозитория

```bash
git clone https://github.com/gusikhinserg04/customer-churn-ml.git
cd customer-churn-ml
```

### 2. Создание виртуального окружения

Для Windows PowerShell:

```powershell
python -m venv .venv
.\.venv\Scripts\Activate.ps1
```

Если PowerShell блокирует выполнение скрипта активации, можно использовать командную строку Windows:

```bat
.venv\Scripts\activate.bat
```

### 3. Установка зависимостей

```bash
python -m pip install --upgrade pip
pip install -r requirements.txt
```

### 4. Запуск проекта

```bash
python main.py
```

Скрипт загружает данные, выполняет предобработку, обучает модель, выводит метрики качества и сохраняет обученный конвейер в файл `models/churn_model.joblib`.

Убедитесь, что датасет находится по пути, указанному в `main.py`.

## Результаты работы

При успешном запуске проект формирует:

* Метрики качества модели в терминале.
* Матрицу ошибок классификации.
* Файл обученной модели `models/churn_model.joblib`.
